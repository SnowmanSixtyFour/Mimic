An atmospheric Minecraft horror mod, that adds a player-like mimic to your world.
# About
The Mimic adds a single new entity— simply known as the Mimic.

It will leave traces around your world to make itself known.
### Q&A
<b>What does this mod run on?</b>

The mod supports both [Fabric](https://fabricmc.net/use/installer/) and [Forge](https://files.minecraftforge.net/net/minecraftforge/forge/) on version 1.21.1.

<b>Can I use this in a video?</b>

You are free to make any videos on the mod as you please, so long as you credit it in some way.
